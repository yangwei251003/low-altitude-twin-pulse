# Rock07 ARM 与材质响应：只读诊断

2026-10-19。本轮只解码原 PNG、读取原生 `.blend` 的 SDNA 节点/接线/LOD 数量；没有 Blender/Godot/GPU、图像编辑、模型修改或新资源下载。数值与完整接线见 `arm_material_diagnosis.json`。原 P12 与独立诊断的 38 个 manifest 文件逐一核对不变，新报告不回写旧 manifest。

原 `rock_07_arm_1k.png` 为 1024² RGB，SHA256 `317220fff40e68914240a912042beaf4c5df1262985aaad5582352ea450f2550`。下表是完整 atlas 的 8-bit 值；Non-Color 输入除以 255，不作 sRGB 转换。

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| R / AO | 0–255 | 0 | 226 | 246 | 251 | 255 | 205.7103 / 87.1197 | 219 |
| G / Roughness | 76–76 | 76 | 76 | 76 | 76 | 76 | 76 / 0 | 1 |

G 在每个像素均为 **0.298039**，不是有空间变化的粗糙度。B 为全零。AO 统计包含未用/填充区域，不能把全图最小值解释为可见表面的孔洞深度；G/B 恒值结论不受 UV 子集影响。

## 保存源中的真实接线

`isolated_diagnostic.blend` 实际接线为原 UVMap → 三张图；Diffuse sRGB → Base Color；ARM Non-Color → Separate Color，Green → Roughness，Blue → Metallic；NormalGL Non-Color → Tangent NormalMap（同 UVMap，Strength 1）→ Normal。R 没有接入色图。Coat、Transmission、Emission 均为 0，IOR 为 1.5。未发现通道对调或把 ARM 当 sRGB 的问题。Principled 未连接的 Roughness 默认 0.5 会被实际 G 连线覆盖，不能据默认值判断渲染响应。

原作者 `rock_07_1k.blend` 则把独立 `//textures/rock_07_rough_1k.exr` 接 Roughness（Non-Color），IOR 为 1.45；它没有用当前 ARM G 代替。独立 Rough 未在本轮下载/采样，不能断言其数值与 ARM 一样，也不能把 P12 的“原 PNG 未改”扩大为“完整复现作者原材质”。此前没有核验两者等价，是本次需要明确补充的限制。

[官方页面](https://polyhaven.com/a/rock_07) 和已保存 API 元数据只称风化石、土色，没有说明采集时湿润。当前统一低粗糙度能解释明显湿亮响应；它与棚拍光照、切线法线各贡献多少未做受控渲染，不能确认扫描本身就是湿石。暖棕属于原 Diffuse 色信息，不能全归因于粗糙度。官方 Blender Principled 页面本次返回 402，未将其写成已读证据。

## 两种受限材质建议，尚未实施

保留官方图与原件，只建立共享纹理的独立材质实例；UV、法线强度 1、金属度 0、Coat/Transmission 0 不变，IOR 还原作者值 1.45。先不改原色，不通过涂灰或增加噪声掩盖问题。

- **干岸石**：Roughness 先设 0.72，限制试验范围 0.65–0.80。当前 G 恒定，所以直接换有限标量比把恒值假装成“扫描粗糙变化”诚实。将来若取得作者独立 Rough，再保留其变化并限定到干态区间，需先实际核验。
- **沟内湿石**：Roughness 先设 0.42，范围 0.35–0.50；只给真实湿沟内的少量石块，不整组湿亮。先保留原 Base Color，若实际镜头仍需湿润色差，线性颜色最多乘 0.90–1.00，不烘黑 AO、不加清漆层。待真实地形位置确定再选干湿实例。

这些是可验证的艺术参数起点，不是本轮已渲染/已通过的结果。
