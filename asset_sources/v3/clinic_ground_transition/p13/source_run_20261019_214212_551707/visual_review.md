The long exposed closing side of this isolated preview also contributes to a cut-out slab/carpet impression; that side is intended to be buried in a real terrain join, but burying it alone would not fix the visible flat upper composition.

Recommendation: freeze this bounded source study and do not bake/export it. Do not automatically deepen every groove, add stone counts, or start P14. Root should decide its priority relative to the broader true-terrain work.
