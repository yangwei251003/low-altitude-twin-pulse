# I2 重力水箱 A：精确基础形体准备

`build_base_v1.py` 根据真实 `i2_clinic_layout.json` 构形，源原点对应 Godot 世界 `(-9,6,-7)`；采用 `(GodotX,-GodotZ,GodotY)` 转入 Blender。它目前只做 A，不做滑阀 B、不做水城场景。

准备阶段未启动 Blender；2026-10-18 已在根授权窗口执行，首轮材质节点失败、第二轮实际产图。详见 `evidence/BASE_FORM_REVIEW.md`。后续仍须协调独占窗口。脚本不会导出 GLB，也不写 `assets`、布局或生产代码；现有 PBR/GLB 与旧仓体归档全部只读。

设计内容：

- 保留三个实际旧台/柱实体和罐底的独立可编辑盒体；可见副本用正交并集外表面消除内部重复面，不抬高 Y6 台面避闪。
- 7×4.3×0.4 m 主台、3.3×1.3×0.4 m 局部舌台、唯一 0.6×0.6×5.6 m 柱。柱脚不外扩。
- 独立正面窗与窄框恰好分割原透明墙的范围；不增加交叉筋挡住水线，开顶与浅色内壁保持。
- `SourceWaterBase` 为资产局部原点；预览 3200 L 水另置 `PREVIEW_ONLY_DO_NOT_EXPORT`，不属于永久模型，不代表运行水状态已经接入。
- 0.4 m 台深读成闭合钢制箱梁；内部腹板/隔板作为可编辑构造指示隐藏渲染，严格位于已有实体。没有工程承载认证或有限元结论。

本轮实际输出：`clinic_gravity_base_v1.blend`、`evidence/base_geometry_v1.json`、`evidence/clinic_gravity_base_v1.png`。脚本保护已有同名 `.blend`，避免未授权覆盖一次已记录试片。基本色材质/初始平面 UV 不是最终 PBR；闭边与几条射线也不冒充完整自交/机体物理验收。

执行方法（**仅根释放窗口后**）：已安装 Blender 5.2 的后台 Python，CPU 固定 2 线程。预计构造数秒，单张 1280×1280 / 20 samples 基础图约 30–60 秒；实际 PID、耗时与失败会在日志/报告中记录。下一步须先看图，再决定 PBR 及真正游戏镜头。
