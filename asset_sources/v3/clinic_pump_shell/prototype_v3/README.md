## 默认镜头量级

源码相机方向 `(32,39,32)`、默认 size=26、项目 1280×720；Camera3D 默认 KEEP_HEIGHT=1，因此未缩短方向约 27.69px/m，再计入对应表面的轴向投影。相机属性依据 [Godot Camera3D 官方文档](https://docs.godotengine.org/en/stable/classes/class_camera3d.html)。`projection_estimate.json` 保存完整计算。

- V2 8–33mm 边缘支持域仅约 **0.19–0.77px**。再乘渐变及低覆盖后，确实难以在默认镜头形成稳定读色。
- V3 6–9cm 局部边角片段约 **1.40–2.10px** 宽；0.38–0.65m 不等长片段约 9–15px 长。
- 水迹全宽 4–7cm 约 **0.94–1.64px**，0.45–0.72m 长约 **9–15px**。其边缘不会再整条线性削到只剩亚像素暗芯，但仍需实际抗锯齿/游戏光照检验。
- 代表墙脚湿斑约 **17–29px** 宽、**5–6px** 高，使用明确位置与宽缓轮廓，非增大全域噪声。

这些是长度投影估算，不是 GPU 像素测量；实际可见覆盖还受遮挡、滤波、明暗和材质对比影响。
