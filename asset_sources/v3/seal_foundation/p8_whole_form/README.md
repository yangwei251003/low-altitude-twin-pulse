# P8 原创整块宽面形体 — 冻结，数值通过，美术自审退回

## 本轮解除的错误中间约束

旧扫描中段的 6 倍纵向拉伸、P6/P7 的 118 条补片边以及旧水线轮廓，都是此前实现选择，并非用户对最终游戏的要求。本轮放弃这些拓扑和轮廓，不继承 P5 网格，也不将新的艺术形体强塞回旧扫描表面。

继续保留真实接口：冻结封印闸 P3 的 28 个底面三角、实际门底顶 Y=2.9、门的 6m 行程、独立承梁、HX02 完整低飞包络及 0.1m 余量、床 Y=-3.2、水 Y=-2.2。新水线按新模型实际截面重新计算，没有修改生产水网。

## 一次明确构图及实际失败点

使用一个原创连续厚腹，由 19 个有目的、不等大的半空间平面构造闭体。两长侧采用不同的斜面组合，前后断面不对称，底脚为宽实体接床，顶部收向独立神殿承梁。源码保存每个平面的法向/偏移以及对应顶点，Blender 保留 19 个可编辑大多边形。没有扫描网格、等距环挤出、三块重复柱、随机噪声或自动盲减面。

两张基础色离线图均已实际查看。厚腹完整，纵沟与补片边消失；但整体变成过度简化的凸切面块/配重石。全凸半空间组合无法形成参考 v2 的非凸断阶、宽裂面相互咬合与不等高自然肩。大面数量满足构图意向不代表艺术还原，低三角数也不是本轮的成功标准。闭门装配中这种人工块感仍明显。

因此本轮美术自审退回并冻结；不添加纹理遮掩，不开新版本，不扩展装饰，也不声称原方法有保证。保留完整失败证据交根重新排制作优先级。
