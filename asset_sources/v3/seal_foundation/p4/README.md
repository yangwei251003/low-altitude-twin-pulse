# 封印闸基座 P4：截面可行性检查，未建模

2026-10-18。仅在新 P4 目录读取原生 Boulder 01 LOD3 的真实三角数据，检查五对预先确定的水平裁切截面。没有启动 Blender，没有修改旧源、参考或运行资源，没有产生 P4 模型、图片、贴图或 GLB。

**结果：0/5 截面覆盖完整 1.3×7.3m 承梁底面，按根代理约定停止。** 这并不证明所有可能姿态均不可行；本轮没有无界搜索其他高度、旋转或位置。

## 方法与实际约束

- 原生源：`asset_sources/v3/growth_approach/resource_recovery/boulder_01/boulder_01_1k.blend`，SHA256 `8f8004fb52ebd00c4702a50873ac799e7bd7a0bea3415f2d8bc9986e1c58e371`。Poly Haven，作者 Rico Cilliers，模型 CC0，<https://polyhaven.com/a/boulder_01>。
- 数据读取复用 P2 实际原生 Blender 提取的 `native_mesh_read.json`；该文件只读，哈希写入报告。
- 最长主轴沿 Godot Z，中轴沿 Y，薄轴沿 X。先统一放大 4.6853658133 倍，使 Z 长 9m；X/Z 居中。此时包围盒 X ±2.248777m、Z ±4.5m，原 Y 从 0 到 6.100336m。
- 五个上切面固定取原高的 38%、43%、48%、53%、58%；下切面固定 17%。这是本轮有限候选，不是审美标准。只根据真实三角与平面交线构造多边形，原闭体奇偶射线筛除空洞；截点按 1 微米合并。
- 判据先查零余量完整梁底，再单独查四边各 0.1m 的明确余量。零余量均失败，所以结果不依赖余量取值。
- 预定后续变换本应将下截面映至世界 Y−3.2，上截面映至梁底 Y2.45；本轮没有实际执行该裁切或伸长。源到世界的 X/Z 偏移仍计划为 `(6,26)`。
