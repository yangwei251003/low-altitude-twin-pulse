# P7 单侧宽面连接试片 — 数值通过，非整件美术通过

本轮只替换 P5 默认可见 +X 侧的一段水线上方壁面。没有扩展其他侧壁，没有 PBR、GLB、运行世界改动或 Godot 验收。P5/P6 原件保持冻结。

## 方法及真实结果

P6 的 118 条三维接缝是有效闭环，但顶边投到 YZ 后存在回走及 17 对非相邻共线重叠。P7 不排序、合并或删除原边，也不移动任何三维边界顶点；仅将原环的四段按三维累计弧长映射到简单矩形参数域。CDT 在此参数域处理，输出再引用原 BMVert 和同一组 6 个宽面控制点。参数域检查同时检查严格横穿及共线重叠。

实际数值结果：

- 118 条原边全部保留，每条恰好连接 1 个保留面和 1 个新面，边界坐标完全未动。
- 新试片 128 三角，内部 4 个三角组成 2 个宽斜平面；过渡三角保持原复杂边界。
- 主岩体 3,148 → 4,348 三角。增量主要来自界定试片时四个平面切分原面；这是拓扑细分，不是新增另一侧的造型。
- 主岩体 1 连续组件、0 开边、0 非流形边、正体积；当前非相邻三角交叉及独立共面面积重叠审计没有检出交叉。
- 床面、梁下承托面、四个肩面保留：旧顶点到新表面距离均为 0，面面积差均小于 0.0000005 m²。承梁独立网格哈希不变。
- 真实水位截面仍为 1 环，双向顶点到线段误差 0.000000238418579 m。
- 岩体体积 123.859103309 → 124.077389873 m³，增加 0.218286564 m³；三个轴的 AABB 外扩均为 0。这里没有测布尔差体积，不能解读为每处原表面均无局部外凸。
- 改区 local Y=1..4.25，模型世界平移 (6,-3.2,26)，对应 world Y=-2.2..1.05；低飞扩展包络底 Y=2.56 未被改区触及。上部原肩与承梁保护检查保持。没有新 Godot 机体扫掠结论。
- 报告 146/146 项包含 118 个 CDT 顶点保留断言，不能宣传为 146 个独立造型/物理验收项目。

## 进程及首次实现错误

第一轮 PID 42620，2.95 秒 exit 1，无渲染：新面标签数据层在缓存 BMFace 引用后创建，使缓存失效，尚未执行几何替换。原脚本/日志/报告/进程数据按字节保留于 `initial_label_handle_failure/`。

唯一修复是将标签层初始化前移到采集 BMFace 引用之前，几何参数及造型不变。之后 PID 2024，CPU 2 线程，93.24 秒 exit 0；数值先通过，再输出授权的两张图。没有第二套造型/参数扫描。
