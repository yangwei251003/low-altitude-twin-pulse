# 封印闸基座 P2：天然岩体首轮，已自审退回并冻结

2026-10-18。仅源形研究；**不是集成候选、没有 PBR/GLB、没有实机验证**。本轮只写此 P2 目录。旧 P1、批准参考、专业资源原件、封印闸 P3 和世界数据均未改。

## 实际制作

- 用 Poly Haven **Boulder 01 的原生 `boulder_01_LOD3`** 三个独立副本作上部岩体，统一缩放 3.08 倍，沿深度轴分别刚性转 −2° / +2° / 0°。没有各轴压扁或整体顶点变形。
- 用原生 **Namaqualand Boulder 03 `namaqualand_boulder_03_LOD3`**，统一缩放 2.0 倍并刚性换轴作下部承托。源物件的隐藏副本保留在 `SOURCE_NaturalLOD3_ReadOnlyCopies`。
- 各主岩保留独立编辑结构，做门底 Y6.1、两端 Z±3.75 与自由宽度 X±1.5 的局部裁切；三块顶面仅用浅层分区切削避免重叠共面。没有整件 voxel / 合并重建。
- 原精确八角仅由 **1.015m 高的水下接合体**维持，水线为局部 Y1，底面 Y0。它没有被拉成六米主墙；Nama 在水线附近另作向上放开的接口裁切。但这类接合仍需在真实水面中检查，不能凭该图证明隐蔽。
- 当前输出基础色，石面采用平面法线显示；**没有以扫描纹理代替 F-B 手绘材质，也没有新生成图片**。
- 实际冻结封印闸 P3 从 GLB 只读导入，门中心置于基座局部 `(0,8.6,0)`，实际门底为 Y6.1。它在单独 collection 中作装配参照，不属于新基座；渲染临时使用中性基础色，并非修改 P3 材质。

## 结果：15/17 检查通过，整件不通过

`form_report.json` 是原始结果，未放宽断言。实际 23,406 三角、5 个可见基座 mesh（另外有源副本、参照门和棚拍对象，不计入资产）。

已验证：5 个独立岩体/接合体各 1 连通组件、0 开边、0 非流形边、正体积；本轮非相邻三角穿越和独立共面候选检查均未发现每块自交。独立块之间有意交埋，不被误报为自交；该检查排除共享顶点的三角对，不是数学意义的所有情况证明。

- 冻结 P3 **36 个实际下沿顶点**均由 Y6.1 岩面支撑。
- 保守名义 1×7m 的 **145 点中 8 点失败**，都在 X=+0.5：Z=−1.75、−1.5、−1.25、0.75、1、3、3.25、3.5。部分落到较低天然岩面，最后一点落到水下接合体。不能把真实顶点通过换称完整名义面积通过。
- 浅座分区的内部面并非完全隐藏：中块可见约 **0.03194m²**，东块约 **0.02607m²**，本轮检查失败。该采样仅审指定浅座面，不涵盖所有可能可见接缝。
- 实际包围：X `[−1.4577547,1.5]`、Y `[−0.0000000037,6.0999999]`、Z `[−3.75,3.75]`，底部微小负值为浮点误差。相对旧 X±1.25 向负侧外扩 **0.20775m**、正侧 **0.25m**，在本轮允许的最大 3m 宽内；**不是仍满足旧宽**。
- 水线实际三角截面未越出既有八角，水下接合体保留该八角的全边界，底面原位；没有改动裁水世界数据。

## 实际图像自审：退回原因

1. 三块主岩虽使用真实专业源，却基本同向复制；相同的天然面和凸点重复出现，读成三列凸块，不能还原参考三四段错位宽断岩。
2. X=+1.5 的裁宽在正面留下三处醒目的平切疤。没有全轴压扁，但**局部裁切量和摆位仍破坏了关键自然面**；“使用真实源”不等于自然主形保留成功。
3. 上部有整片平切顶，下部 Nama 与主岩之间缩腰，局部读成悬挑帽体；参考是完整连续厚岩，当前未达到。
4. 平面着色把扫描低模的细三角表现得碎。即使后续改变法线，也不能据此掩盖上述大形、平切疤和支撑问题。
5. 装配图能看见真实门底方向与贴合，但门顶左侧少量出画，**不能当完整门外观审查图**。基础岩体图本身完整。当前按首轮后停止的授权保留原图，不再重拍或修模。

没有继续第二版、没有烘焙、没有导出候选 GLB。后续必须由 root 看原图与失败证据后确定是否值得进一步修订；不能只补纹理或小石块把这一版称为通过。

- `seal_foundation_p2.blend`：可编辑源；默认基础岩体相机，参照门 render 隐藏，可自行切换集合。
- `seal_foundation_p2_basic.png`：基础色单件全图，实际 Blender 离线图。
- `seal_foundation_p2_gate_assembly.png`：冻结门 P3 与新基座装配方向图，实际 Blender 离线图；不是游戏截图。
- `build_foundation_p2.py` / `build_p2.log`：唯一构造及两图过程。Blender 5.2.1 LTS、Cycles CPU、2 线程、12 samples、1200×960。
- 实际原生读取 PID **33296**，exit 0；构造/渲染 PID **35588**，2026-10-18 08:20:36 开始、08:21:35 左右结束，exit 0，脚本计时 **58.695s**。无 Godot、无 GPU 测量。
- `native_mesh_read.json`：实际 Blender 读取两件原生 LOD3 的几何/主轴/原始修改器记录。复制基座使用原始网格，不假称求值过 DataTransfer 等源修改器。
- `plan_pose.py` / `rigid_pose_candidates.json`：轻量截面推演。AABB 不被当作实际门底覆盖证明。
- `form_report.json`：原始拓扑/接触/包围/可见内缝结果与全部只读输入哈希。
- `manifest.json` / `selfcheck.json`：本目录逐文件字节校验，另复核只读输入未变。
