# P1 主形实施范围

根已实际看单件参考并授权本轮主形候选。保留原参考/接口卡；当前只制作一个可编辑基础色源和一张离线图，不烘焙、不导出GLB、不改运行。

用一个闭合厚主体承担全部地基与门底支撑。正背两个主要岩面沿7.5米长轴分为少量宽断面，凹肩高度按所在长轴位置和侧面分别错开；深度只向八角包络内退，让上下岩面实际连接。没有独立薄柱、外露隐藏盒、体素百万面或盖在细腰上的单独顶盘。

源脚本保留三个约束截面：底部局部Y0、水线Y1.0的原八角环；顶部局部Y6.1支承实际门底。水线以下是一米完整暗湿基底，其余侧面几何展示宽斜裂/不等高凹肩。顶部周缘是厚岩体本身的结束面，中心1×7米门底区域用真实三角射线核查。

首图用三种基础材质区分干岩、凹肩和最低湿带，没有裂纹图或苔片，以便直接判断轮廓。目标≤约30k三角；首轮按实际主要断面需要建几何，不为填预算增加细噪。检查记录闭合、单组件、固定八角截面、真实支撑、包络、三角数与输入哈希；这些不等于美术通过。
