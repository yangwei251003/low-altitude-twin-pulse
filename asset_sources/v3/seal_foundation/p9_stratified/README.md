默认镜头和实际闭门装配两图均已实际查看。前后高肩、中间低台及其两侧凹入转折已经可见，梁下连续承载也可读，比 P8 的单一凸配重体更接近层台关系。局限仍明显：大平面和中央岩骨的长直边仍偏建筑切块；下沿几处交叠露成薄楔，不能宣称已还原参考自然岩层。每块内部虽厚实，前岩层与连续岩骨交叠约 22.75/28.70 m³，外露部分因而较薄。这是具体形体问题，不能用材质细噪或数值通过遮盖。

本轮只供审查，不在此继续参数搜索或加新版本。27 项检查和 176 三角均不作为审美通过理由。
