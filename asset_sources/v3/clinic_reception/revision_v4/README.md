## 尺寸与状态边界

候选**设计 AABB**保持局部 X[-5,5]、Y[-0.4,3.3]、Z[-4,4]；未来世界原点仍(7,5,-6)。这不是已执行实测值。3m宽/3m高前廊、3.4×2.8m门洞、旧两端接口保留；门/屋顶/灯/担架/床/柜台仍独立。未新增任何地下承重。柜台前区仅是源空间检查，尚非两机型实际入室/转向验证。

正常屋顶仍可能遮住默认固定俯视下的柜台，这是实体屋顶的真实限制。本版不宣称靠换摆位就让玩家透视屋顶：外部标识解决未淡出时用途，实际屋顶遮挡控制留给后续 root 集成。可选 `--entry-view` 只输出正常屋顶的低位正门诊断图，明确不是游戏默认相机。

## 入口和证据

`build_reception_v4.py` 先核对冻结 blend 与只读 helper SHA，输出本目录 source blend、真实边界/角柱/柜台视线报告；加 `--render-pair` 生成正常/淡出两图。独立屋面材质淡出只作诊断，不污染墙、家具或标牌。

```text
blender.exe -b -t 2 --python-exit-code 2 --python .../revision_v4/build_reception_v4.py -- --render-pair
```

须等 root CPU2 窗口并由外层有界进程控制器启动。`preparation.json`保留执行前历史记录（measured_mesh_bounds=null、rendered=false）；当前执行证据以`execution_manifest.json`和下节为准，不能混作同一阶段。
