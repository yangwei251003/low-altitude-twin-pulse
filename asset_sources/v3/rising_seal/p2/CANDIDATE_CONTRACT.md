# F1 升降封印闸 P2 候选接口

本件是整体升降的独立石闸，不是固定门框，也不是最终美术通过。原型参考由根线程生成并采用；运行场景、交互、防夹、同步及世界碰撞均由根线程接入。

## 坐标与节点

模型中心为原点，Godot X 是厚度、Y 向上、Z 是横向。全部可见几何须处于 X±0.5、Y±2.5、Z±3.5 米之内，底接面 Y=-2.5。闭合/开启世界中心和 6 米升程沿用共享资产卡；本 GLB 不内置运动动画。

实际导出根 `RisingSealP2` 下四个网格：`StoneMasses`（石块及封闭缝底）、`LivingRoots`（两侧连续主根及并合支叉）、`BronzeFittings`（真正浅槽镶铜、跨边扣件及核心金属环）、`SealEnergyGlass`（仅核心实际发光面，可独立调节，基础 emission strength 0.12）。以最终 `glb_readback.json` 的实际节点列表为准，不能用文案替代读回。

锚点保留：`Centre=(0,0,0)`、`BottomContact=(0,-2.5,0)`、`StateInlay=(0.49,-0.1,0)`，均为 Godot 模型局部坐标。所有装饰随闸板一起移动。没有独立固定地面的根。

碰撞建议保持原整板活动阻挡及防夹逻辑；细槽/分片只是表面结构，不应当视为可穿洞。运行包装可以沿用已约定的 1×5×7 包络，实际精细网格由根按需求使用。该建议不等于已经完成真实碰撞测试。

## 制作与证据边界

保留原 P1 只读源。连续主根审查通过版本在 `continuous_roots_v2/` 原字节冻结。当前细化只增宽下段分叉、为铜带切真实浅槽、让扣件跨过板边；上部两个新增小装饰叉在默认角度被遮成尖片，按根授权撤去，不扩大切石。原先明确通过的两根连续主干不删除。

Source 保存独立石块/木根/铜件，隐藏集合保留并合前的根构造。导出副本按材质合并，源不合并覆盖。UV 目标明确为 `SurfaceUV`，源细节 UV 与烘焙目标分开。烘焙基础色/粗糙度/OpenGL 切线法线，外部 PNG 保留；不烘焙灯光、AO 或阴影。GLB 内嵌运行贴图。最终哈希、网格/三角数、材质、边界及锚点以 `export_report.json`、`glb_readback.json` 和 `manifest.json` 为准。

离线图明确区分可编辑源渲染与删除源后真正 GLB 回导渲染；都不是游戏画面。几何闭边/正体积/连通检查不能代替独立三角自交审计，更不能替代游戏运动、防夹、联机或帧率验收。

## 保留的美术差距

六大石面的边带和分片仍偏规则，木根局部切端仍比参考干净、光滑，铜件缺少参考中更丰富的局部氧化与磨边。本轮保持低对比面感，不用迷彩色胞、全域裂纹或发光掩盖结构问题。后续须在真实游戏光照和固定相机尺度决定这些差距的优先级。
