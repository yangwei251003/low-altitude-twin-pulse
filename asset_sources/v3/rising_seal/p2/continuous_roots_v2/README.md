# F1 升降封印闸 P2：连续主根修正源，待主形审查

本目录只包含独立 P2 可编辑源、基础材质图与检查记录，没有制作 PBR atlas、GLB 或游戏导入。P1、运行资产和共享卡未修改。根线程已采用单件参考，原共享卡“概念准备”是先前阶段文字；本轮遵循当前任务授权，不擅自改卡。

## 依据与差距拆解

已经完整读取 `docs/v3/assets/F1_RISING_SEAL.md`、参考同目录 `provenance-v1.json`，并实际查看批准参考、P1 `first_form_rejected` 和当前 P1 两张图。

1. 参考的石块厚度、自然断边和宽切面共同读形；P1 是薄覆板置于规则连续背板，均匀倒角接近柜门。其 Voronoi 改动只是给平面换迷彩色块，没有改变石体形状。
2. 参考的根跨过顶边、侧角且有宽叉；P1 根基本停在同一正面深度。再加纹路仍不能形成真实绕角关系。

P2 保留 P1 核心、铜扣、镶嵌通道、Centre/BottomContact/StateInlay 的几何及变换；只替换石体和根。模型仍是 Godot X 厚度、Y 高、Z 横向的 1×5×7m 活动包络，底接面 Y=-2.5，中心/行程规则不改。

## 已做首轮改变

- 六块石体从背深 -0.34m 延伸至约 +0.30m，实际贯穿主要厚度，采用不等宽断边和两片宽前切面；缝后保留闭合石底，不做可飞穿孔。
- 石材只用连续、低对比宽色差，移除 Voronoi 色胞。边缘略暖，未铺满噪点，也未将基础材质冒称最终手绘。
- 两根中心线真实经过前→顶→背，以及前→侧；截面短/长轴比 0.92，保留圆润厚度，配置少量宽叉。根随板一起运动，没有固定地面根。

## 实测结果与首轮失败

第一次构建 36/37：全部闭体和保留对象检查通过，但正 X 达 +0.5067397356m，超过 +0.5m 包络约 6.74mm。因此在出图前主动停止，原始源、报告和日志已按原字节保存到 `envelope_reject_v1/`。

归档时脚本复制发生在编辑之后；已根据记录的逆向补丁恢复该历史脚本，`archive.json` 明确区分“原始数据文件”与“逆补丁恢复、未独立捕获原哈希的脚本”，不把四者都说成独立验证的前版字节。

修正仅将暴露的正面根中心线内移 12mm，不压扁截面。第二轮检查 **37/37** 通过并真正渲染一张图，Blender 退出码 0。实际 Godot bounds：min=(-0.36000001,-2.5,-3.44000006)，max=(0.49306428,2.46676135,3.43000007)。32 个可编辑网格、10,956 三角。所有网格分别闭合且正体积；保留核心/铜件/锚点几何变换哈希与 P1 一致。

这些检查证明闭体、尺寸和保留接口，**不证明美术通过或游戏碰撞/升降/防夹/同步通过**。石体分件与闭合缝底存在设计上的相交，不等于已经成为一个无重叠并集网格。

## 首张图的真实退回点（已归档）

首张图已实际查看，来自可编辑源、P1 同一固定相机、CPU2、12 samples，没有编辑图片。迷彩消失，块体的厚切边开始可见；但两项重要差距仍在：

- 主根绕侧路径穿入未让位的石角，虽是连续闭体，正面却读成上下断开的木段。不能以闭体数值替代可见连续性。
- 石面依然规整平滑，边带像整齐切削，尚未达到参考的自然厚石面感；根也偏干净、圆滑。

根线程实际看图后确认退回，并授权让主叉保持正面连续，只有支叉绕侧，为顶角/侧角的实际根径削出局部石床。修改前的 9 个源、图、日志、报告与清单已原字节归档到 `occluded_roots_v1/`，该目录 `archive.json` 记录逐文件哈希，不覆盖负面证据。

## 当前连续主根修正

- 两侧主根均沿正面从顶角贯穿到底；顶端确实绕回板后，侧支根另行绕侧，主干不再为了绕角隐藏于石内。圆润截面维持短/长轴比 0.92，没有压成薄带。
- 主根与两条支叉各经过实际 Exact Boolean 并为一个连通网格；隐藏集合 `EditableRootConstructionPieces_Hidden` 保留未并合的可编辑构造分件。
- 按根路径在六石体上切真实浅石床，让木石交界有位置依据；没有把原石体全部掏空。前面宽切面的深差增加至厘米级，不加入密集色胞。
- 核心、铜扣、铜通道和原锚点仍保持 P1 几何及变换。铜带贴面方式是明确待修项，未暗中算作已还原。

这轮实际运行 **35/35** 通过，Blender 退出码 0，耗时约 28 秒：28 个可见网格、15,660 三角。测试数量由 37 变为 35，是四个独立支根并入两条主根后减少四项逐网格检查，同时新增两条主根单连通检查，未放宽原尺寸及接口门槛。Godot bounds：min=(-0.36000001,-2.5,-3.45647383)，max=(0.49000001,2.46676135,3.45210433)。底接面仍 Y=-2.5。

当前 `rising_seal_source_p2.png` 已实际查看：连续性和圆厚度比归档版改善，顶角绕回与宽前切面可辨。仍有主根偏光滑、支叉切端偏尖、六大石面规整和铜带悬贴的差距，尚未达到批准参考的石木表面与嵌槽铜件表现。本图只用于基础主形判断，不以缺少最终纹理掩饰或否认几何差异；等待根线程实际审图后决定下一阶段，不自动烘焙。

检查范围为逐件边流形、正体积、主根连通性、包络和保留接口；没有另做三角自交排查，因此不称“完全无自交”。设计上的石块/缝底交埋也仍存在。没有游戏导入、运动、防夹或联机验收。
