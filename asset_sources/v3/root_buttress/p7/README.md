# P7 原比例天然岩层试验 — 自审形体未过

2026-10-18。本目录是方法验证，没有修改 P2 运行四高度、P3 材质候选或 P4/P5/P6，没有纹理烘焙、GLB 导出或 Godot 导入。

## 先推演、后构造

`paper_geometry_plan.json` 来自六块原始岩石的真实水平截面计算。四足中心与每个 R0.75 周界必须同时位于**同一块原始岩石的截面内部**，再选择统一缩放与刚性旋转；不是先把四个区域拉高后宣称覆盖。

本轮选四块：

1. Rock03 统一放大 5.5 倍，原始高度约 45% 处切成 Y10 上层岩面；保留其原始不规则侧边。
2. Rock04 统一放大 4.8 倍、略旋转，底部落到 Y0，作为厚主体。
3. Rock01 统一放大 2 倍，切 Y5，作为左中台。
4. Rock01 统一比例 1 倍、旋转 90°，位于偏后区域，作为短残脊。

四块各轴缩放完全相同，比例差为 0；只有上层、中台两次水平切削以及主体左侧一次局部通路切削。没有逐列拉伸、四个圆垫、方块台阶、体素重塑或随机顶点噪声。原比例变换后的未切件保存在隐藏集合 `P7_RigidNaturalPieces_BeforeCuts`。

## 唯一实际图与判断

`h10_p7_natural_layers_default.png` 是本轮唯一基础色图：可编辑源直接离线渲染，1024×800、Cycles CPU 2 线程、8 samples，与此前默认斜角相同。SapKnot 在石体研究图中隐藏，原几何/UV/变换保留。

**自审形体未过，不进入材质阶段。** 真实改善是没有 P6 的帘状长沟，也没有四个圆垫痕，原岩侧面的不规则结构得以保留。但上层切面过平，四周悬出过多；主体上段自然收窄使整体仍像蘑菇，未形成参考的厚连续前/右岩壁。左中台偏小、后脊仍像孤立石片。自然来源及数值通过均不能代替参考还原。

下一步判断应先解决上层与前/右主体的连续厚度和错层关系；不应继续叠加表面纹理。本目录没有擅自追加下一轮几何或渲染。

## 数值检查与限制

`p7_geometry_report.json` 记录 17/17 项检查通过：四个 R0.75 足区各 193 探针，全部在同一个上层岩面命中 Y10；左中台五点 Y5；原包围盒；Sap 与四锚点哈希；三条前侧 LOS；四块之间三组真实网格表面相交；原目录及运行四 GLB 冻结。总计 32,579 三角。

这是源侧几何检查，**没有全冠兽扫掠、真实游戏相机、性能或真人体验结论**。四块内部仍相交，暂不作为运行碰撞网格；UV 只是临时编辑用投影。没有把扫描摄影贴图作为手绘材质，也没有把单件离线图称为游戏画面。

另一个明确缺陷：报告中上层/左台/后脊的非流形边为 0，主体局部切削后有 **55 条非流形边**，没有被列为通过项。需要在采用此源之前定位原始扫描与切削各自的影响并修复，不能将 17 项通过写成完整网格质量通过。本轮因形体退回，不再追加构造来美化验收数字。
