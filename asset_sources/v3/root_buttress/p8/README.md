# P8 断崖来源研究 — 尚未构造高台

2026-10-18。P7 归档重新读回完整；本轮只调查天然来源并做一张原比例基础色接触图。没有修改旧源、P2 运行四高度、P3 候选、共享代码；没有高台组装、材质烘焙、GLB 导出或游戏验收。

## 来源判断

实际看过 `source_geometry_contact_p8.png`：

| 来源 | 实际轴向宽×高×深 | 本轮判断 |
|---|---:|---|
| A — Rock Face 01 | 4.95×3.56×3.83 m，20,174 三角 | **建议作为主前岩壁形体来源。** 原生已有宽面、错层短岩脊和连续断面；比 Rock Moss Set 的圆岩更贴近批准参考。 |
| B — Rock Face 02 | 2.71×2.47×2.13 m，29,566 三角 | 岩层与侧边缺口可读，但较薄碎，适合作转角、局部侵蚀断面来源，不宜均匀重复铺满主体。 |
| C — 既有 Coast Rocks 原比例裁片 | 4.19×2.03×4.15 m，18,311 三角 | 更像低矮海岸岩带，仍圆润。保留为低岸参考，不建议用它拉高成主断崖。 |

上表尺寸来自下载网格实际顶点包围盒。官方目录中的“宽”值不是相同的轴向包围盒口径；不能用目录 7.1 m/4.9 m 替代实测。

这次找到了更合适的**表面形体来源**，并不代表找到了可以直接导入的完整 H10 高台，也不是美术通过。

## 不能忽略的结构缺口

A/B 是有开边的扫描表皮。为排除 UV 接缝重复顶点的影响，只在临时 BMesh 里焊缝统计：A 仍有 886 条边界边、888 条非流形边；B 为 752/760。原数据没有被修成假闭体。C 是按三角中心选取的 4×4 m 裁片，边缘故意保持开口；三角跨越边界使实际跨度略大于 4 m。

因此不建议把 A/B 直接贴在盒子外面或立成四面围墙。若主代理批准下一阶段，建议：

1. 从 A 保留一段方向一致的天然前壁和邻接上缘；采用统一比例与刚性摆放，让岩层方向连续。
2. 以其实际边界构造厚主体，连接上表面、侧壁和背面，明确修复开边、自交及薄片；B 仅用于必要的转角形态参考。
3. 顶部足区作为同一连续实体的一部分再切削到 Y10，保留四足 R0.75；侧壁必须延续到下部，不能重回“另加一个大顶盖”。
4. 先用基础色检查轮廓、短宽层理和开边修复，再进入 F-B 冷灰宽色块风格化。源摄影纹理不作为最终手绘材质。

上述步骤是基于本轮实际源图的建议，**本轮未执行**。也未用新增纹理掩盖 P7 的蘑菇形体失败。

## 图像与证据口径

`source_geometry_contact_p8.png`：三个来源同一世界尺度，只有平移，没有拉伸、旋转变形、重拓扑或合成高台。共享灰材，不使用原始照片或法线贴图。Cycles CPU 2 线程、12 samples、1600×850。源场景为 `source_geometry_contact_p8.blend`。

图中 A/B 仅作源外形比较；缺少的背面或底面不由地面阴影替代。C 的裁切开边也不作为碰撞体。`contact_report.json` 记录实际拓扑统计、摆位、渲染和哈希。只修过一次字幕高度以避免文字被地面遮挡，岩体数据未变；最终交付一张接触图。

`manifest.json` / `selfcheck.json` 只校验证据与旧资产字节，不是 H10 的美术、碰撞、性能或游戏验收。
