# P10 对 P9 的有界修形

范围只在当前 P10 源目录。P9、P3 与运行 P2 保持冻结；不烘焙、不导出、不跑引擎。

从 P9 的实际可编辑源读取其归档的完整闭合岩体，保留四块天然壁面的全部坐标和原刚性旋转、统一缩放；不重新做另一种整体高台。

1. 四角：原四条平直连接带，各用不同天然深度段的相位建立弧折连接。端点与既有岩壁相接，新连接处仍明确属于作者补面；不会把新角部说成未经修改的扫描原面。调整始终位于既有角端点的包围范围内。
2. 背脊：取消 P9 的小直角后块。用一块闭合空气切体从原厚岩削出宽且偏心的斜脊，前/左/右以不同斜率接回主面，本体保持连通。
3. 顶缘：前、右及左后侧分别在宽区域下降，最大不超过0.6m。四个足点周围半径1m保持Y10，覆盖实际R0.75足区及裁切网格插值误差；不为了消除平面而破坏中央站立用途。左Y5台沿仍采用P9同一局部斜切。

实际验证：单组件/零开边/零非流形、原边界和地面、四足各193探针、中台五点、Sap/四锚点字节摘要、3条LOS、已冻结源与运行资产哈希。截面面积仍输出，但没有新增审美数值门槛。
