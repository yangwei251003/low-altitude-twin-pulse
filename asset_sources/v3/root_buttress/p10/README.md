# P10 H10 岩台 — P9 有界修形

**状态：一轮基础色修形与几何检查完成，待主线程图像审查；不是最终美术通过。** 只写本目录，没有材质烘焙、GLB、运行修改或引擎测试。CPU2 渲染已结束并交回岸肩代理。

## 从 P9 实际改了哪里

以冻结的 P9 `.blend` 中 `ClosedFullHeightBody_BeforeTopAndShelfCuts` 为起点。四面天然壁的 18,468 个顶点在局部切削前保持原坐标、原刚性倾转和统一缩放。没有从零生成另一种高台。

- 四角：改动原人工连接带的 1,296 个顶点，各角使用不同天然采样位置/相位连接。端点接回原壁面，全部在原角部范围内。新角部仍是重建补面，不是未经修改的原始扫描网格。
- 背脊：P9 小直角块改成从同一厚实体保留下来的偏心宽斜脊，三个方向斜率不同，没有另放浮石或重叠薄片。
- 顶缘：前、右与左后宽区域局部降低，最大设计降幅 0.6m。足点周围半径1m保护区维持Y10，覆盖实际R0.75及裁切采样误差；中央宽顶继续承担四足落地用途。左Y5中台沿用P9同一斜切。

## 实看同机位图的判断

实际查看 `h10_p10_refined_cliff_default.png`：背部小盒已消失；顶缘不再全长等高直切，转角的连接带宽度与形状有变化；连续天然层理与厚主体保留。

仍有差距：后脊看起来偏连续规则斜坡，斜边有细小锯齿切线；前角还可见较平整的连接面；重复使用同一来源段的四壁仍有相近层纹节奏。宽平顶是保留的功能面，本轮没有为了消除平面而破坏支撑。未增加根、苔藓或纹理掩盖这些形体问题。
