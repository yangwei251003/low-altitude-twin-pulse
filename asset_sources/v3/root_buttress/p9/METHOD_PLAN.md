# P9 连续厚断崖主体 — 构造前推演

本阶段只形成基础色可编辑形体，不烘焙、不导出 GLB、不改运行 P2 或已冻结 P3–P8。

## 来源、坐标与厚度

采用 P8 已实际查看的 Rock Face 01 天然层理。先对实际三角面做正面截面采样，测量岩壁本身的平均倾斜；必要时只刚性倾转，统一缩放约 3 倍。采样用于重建可闭合的表面拓扑，不允许逐列改变高度，也不将原面拉成长帘。原始源与未加工轮廓须保留。

选择前、右方向的连续天然表面段；两面用相交岩层与可读转角连接。内部补实体并闭合，外面不能露出补体盒面。顶面来自这个实体的平切，不另制盖盘。左右/前后轮廓应由源岩层决定，再进行有界裁切，不能围绕同一圆环逐层随机改半径。

## 中台与背脊

LowerShelf=(-3.7,5,3.2)。四足左前中心(-2.54,2.17)，R0.75 区在 `-X+Z≤5.771` 内；中台五点探针则 `-X+Z≥6.65`。因此可用约 `-X+Z=6.25` 的局部斜断面在 Y5 以上释放左前角，而不破坏左前足。中台属于主体下层伸出，不靠浮置一小块石头。

背脊保留主体偏后的一小段原高度，最高不超过11.932，必须与主身连通。不能再摆放孤立石片。

## 构造前后均需检查

- 主体 Y2、Y5 附近、Y8、Y9.9 实际横截面面积/宽深与闭合回路，记录是否上宽中窄；不以单一包围盒替代截面检查。
- 顶面四足各 R0.75 的 193 个探针，全部来自同一连通主体的 Y10 面。
- SapKnot 原始几何/UV/变换与四锚点不变；三条前侧 LOS；原包围盒和 Y0 地基。
- 主岩体单一连通分量、无边界边/非流形边、法线与体积有效，完成这些后才出一张基础色图。
- 数字通过后仍要实看：必须是连续厚岩壁，不是蘑菇、大盘、薄围墙或规则盒面；不满足即保留失败证据并停止材质阶段。

当前文档是推演，不是已完成构造或审美验收。实际截面输出将在 `source_section_plan.json` 与后续构造报告记录。
