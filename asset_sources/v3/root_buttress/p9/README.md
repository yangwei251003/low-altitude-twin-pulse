顶面与左 Y5 中台从同一个厚实体减切。后脊由本体保留，最终版本没有将重叠薄片并回主体。原 SapKnot 几何、UV、世界变换和四锚点保持；本轮石体专图将 SapKnot 隐藏，不表示它被删除。

`p9_geometry_report.json` 为实际 Blender 结果，共 15 项检查通过：

- 33,786 个三角形，1 个连通主体，0 条边界边、0 条非流形边；正体积约 962.757m³。
- 四足各 193 个向下射线采样，R0.75 区全部 Y10；左中台 5 点全部 Y5。
- 原包围盒内：Godot min=(-6.5500,0,-6.6644)，max=(6.6644,11.2000,6.6644)。
- SapKnot 与四锚点摘要不变，三条既定前侧 LOS 通过；冻结源与运行 P2 字节未变。
- Y2/4.95/5.05/8/9.9 横截面均为单闭环，面积依次为 107.279 / 89.331 / 85.069 / 78.890 / 95.428m²。中段最小与上段面积比 82.669%，只是形态诊断数据；先前自设 85% 不是用户或玩法硬门槛，已纠正为不以此判定通过或失败。厚岩壁是否成立仍需看图。

没有真实 Godot 相机、完整冠兽碰撞或迁移测试；数值闭合不代表最终美术通过。UV 仅为临时平面坐标，无本轮材质烘焙。
