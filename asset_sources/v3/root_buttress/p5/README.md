# H10 p5：改方法后的形体候选，尚未通过美术

本目录只保存可编辑 Blender 源、基础色/灰材预览与几何检查。没有烘焙、GLB、其它高度派生、Godot 导入或运行资产替换。p3、p4 和四件运行 p2 的记录文件均在构建前后按 SHA256 核对未变。

## 方法与实际来源

本轮不再沿同一环形轮廓逐层连接。七个大小不同的承重实体分别从闭合块体开始，通过数值切平面削切并填封口，互相衔接，构成下基石、前后上层承重块、左侧 Y5 台地、右侧收腰肩、低后脚和短后脊。方向性顶层使用 s = z − 0.22x 的两条错层，下切最深 0.6 米。

切面方法核对了 Blender 官方 [Bisect 手册](https://docs.blender.org/manual/en/latest/modeling/meshes/editing/mesh/bisect.html) 与 [BMesh API](https://docs.blender.org/api/current/bmesh.ops.html?highlight=bmesh)。当前英文直接抓取返回 402；搜索结果中的官方 5.2 手册及 current API 确认数值平面点/法线、Clear Outer 与填口语义，实际使用本机 Blender 5.2.1 的 `bmesh.ops.bisect_plane` 和原生封口。没有安装新工具。

前根为单个闭合扁宽实体，横截面含宽浅纵向折面，沿长轴转折，末端才分两脚；没有三根贯穿全长的并排圆管。右侧是较小的独立嵌岩支根。SapKnot 几何、UV、变换不改，预览材质临时换为基础色。所有网格保留可编辑分件与 SurfaceUV，当前 UV 只用于后续编辑，不作为最终贴图验收。

## 按真实四爪检查

四足来自 `asset_sources/v3/crown/candidates/p6/crown_glb_validation_p6.json` 的实际 GLB 回读，舍弃旧的 XZ±3 草稿。相对 BodyPerch：

| 标记 | X | Y | Z |
|---|---:|---:|---:|
| ClawContact_FL | -2.54 | -3.00 | 2.17 |
| ClawContact_FR | 2.51 | -3.00 | 2.22 |
| ClawContact_BL | -2.28 | -3.00 | -2.50 |
| ClawContact_BR | 2.31 | -3.00 | -2.48 |

主线程已核实整兽 identity 旋转/缩放，只平移到 BodyPerch，并将身体和真实碰撞再抬高 0.025 米。地形目标仍为 Y10。每个真实足点周围 R0.75 用 193 个点检查完整支撑及新根障碍，共 772 点；不再要求整片 R4.2 都是 Y10。

当前 **23/23 Blender 几何检查通过**：还包含 1,225 个中央顶面探针（允许 Y9.4–10）、七岩块封闭流形、两个下切区域、左台、原锚点/Sap 指纹、三条靶 LOS、根与靶接合、UV、包围盒和冻结文件。它们不能替代主线程的完整 p6 冠兽、飞行体和三甲全角度 Godot 扫掠。

当前 13 个可编辑网格、2,290 个三角形。Godot 包围盒 min(-6.30,0,-6.20)、max(5.75430,11.78,6.56627)，在既有允许范围内。准确值、四锚点、实际足点输入 SHA、各个切面的法线/偏移、根横截面和全部检查保存在 `p5_geometry_report.json`。

## 首轮技术退回与修复

`technical_reject_v1/` 保留首轮脚本、两图、日志和报告。首轮原 21 项通过，但实际图出现顶部黑三角夹缝，因此没有把数字通过当作美术通过。前后上层块原先互相覆盖，错层之后再倒角会制造相交边面。

本轮修复将两块上层按同一界面相接，先处理原始外边小倒角，再下切错层，避免在凹折边上生成交叉倒角。另新增中央密集探测与闭合流形检查。修后两张图已逐张实际查看，原有黑夹缝消失；原始失败证据保留，断言未降低。

## 实际自审与限制

**未建议进入材质或批量导出。** 大块错层和单根结构已经替代旧八角桌/并排面条，但七块岩体仍有较多正交边，两条长直下切面像人工开槽，主根断面太均匀仍像弯木板。左台与右侧收腰在轮廓上可读，天然岩体的整体感和根随岩缝生长的形态仍未达到批准参考。这些是几何问题，不能靠苔藓、颜色或高频纹理掩盖。

两张图是同一固定游戏相机方向的独立单件取景：1024×800、正交尺寸 26.5、目标 Godot(0,5.3,0)、Cycles CPU 两线程、8 samples。它们不是游戏画面，也不是与旧游戏截图严格同状态的相机对照。

`root_buttress_h10_form_p5.blend` 保存基础色可编辑源。`h10_p5_basic_default.png` 和 `h10_p5_gray_default.png` 是本轮修后的两图。`build_h10_p5.py --render` 可在同一冻结输入上复现；必须使用 Blender `--python-exit-code 17`，几何失败会停止渲染。已停止 Blender，把机器窗口交回主线程进行独占性能研究，不自行追加下一轮。
