# H10 P12 根截面局部试验

当前交付为可编辑源和一张基础材质离线图，**不是已通过的美术候选，不烘焙、不导出 GLB**。原 P11 和运行四个 P2 GLB 均保持冻结。

本轮先实际查看根线程的 `artifacts/v3/art/20261018_051854_h10_p11/02-p11-candidate-near.png` 与 `03-p11-candidate-lower-root.png`。近景确认：前/右根的截面过扁，宽平切端在真实镜头中比离线图明显。岩体冷灰与 Boss/靶识别的改善已获根线程认可，本轮没有再改岩体或材质方向。

## 方法与实际改动

从冻结 `p11/root_buttress_h10_complete_p11.blend` 打开，仅以其隐藏的天然粗叉源重建 `Root_FrontSap`、`Root_RightFork`。源叉在原 glTF 轴中的范围为 X[-0.600000024,0.400000006]、Y[0.100000001,2.200000048]、Z[-1.462441802,1.002236366]。这是整叉包围，不应当作任一根干的截面直径。

P11 沿壁面法向使用 `.34/.36`，长度和横向叉宽维持原倍率，是扁带感的明确几何成因。P12 将法向恢复为 `.78/.82`，分别约原法向的 2.29/2.28 倍；横向宽度收为 `.90/.88`，长度、上端高度不变。保留源的天然不对称轮廓，增加很小的非对称截面变化；壁面参考在左右 20cm 范围柔化，避免跟随每个细三角面。没有全轴拉伸。

根中心略向岩体内移，末梢按局部高度渐进交埋。脚本有分段整体向内移的边界保护，不逐顶点夹平截面；**本次实际未触发此边界保护**，两根 `max_local_inward_shift` 都是 0。不能把未触发逻辑当成已经发生的修形。前根闭体体积由约 7.01 增至 14.63m³，右根由 4.53 增至 9.10m³；此数字仅说明截面恢复，不是审美阈值。
