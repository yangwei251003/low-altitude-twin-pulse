# H10 p4：形体返修候选

仅为可编辑源与离线造型检查。没有烘焙、GLB 导出、运行资产替换或其它高度量产；不是游戏截图，也不是最终美术通过。

## 返修依据

实际查看了 `artifacts/v3/art/capture-20261018_022355_7ec161` 中 02、05、04、06。p3 的冷中灰与较弱纹理对比在游戏光照下确实改善了冠兽、琥珀靶与岩台之间的分离；但是等宽圆柱轮廓、大平顶和宽直木带仍很突出。该批 02 与后续图的任务状态并非严格一致，不能冒充严格同状态 A/B。

本轮保留 p3 的配色方向，直接修改结构。连续承重岩壁的不同高度使用不同轮廓；左侧保留真实 Y5 台面；右前肩与后方残脊属于大块岩体。根按实际岩面组织路径，分叉处从主根内部生长，避免仅把条带贴在石面上。

## 本轮实际执行的硬边界

- 原点、BodyPerch、HostTarget、LowerShelf 与 SapKnot 原始几何、UV、变换保持不变。
- 中心 R4.2 的 RockMasses 承重面保持 Y10；四足各 9 点另行检查。原有 SapKnot 是单列的冻结交互几何，不用于混淆承重面判断。
- 新根与树皮不得在该安全面上增加障碍；总体不越过旧 X/Z/Y 包围盒，底部不低于 Y0。
- 所有 p3 manifest 文件及四件 p2 运行 GLB 在构建前后逐文件 SHA256 核对。

第三轮结束后，主线程明确修正了下一轮形体约束：四爪接触点周围各 R0.75 米完整保留 Y10，其余中央顶面可向下雕 0.1–0.6 米方向性层裂和非对称凹区，不向上增加障碍，四锚点与 SapKnot 仍冻结。当前图片/17 项报告仍是按原 R4.2 完整平面规则生成的历史候选，尚未按这项新约束重建或重新扫掠；等待主线程看图后选择具体大形修法，不自行追加渲染轮次。

## 文件与复现

`build_h10_form_p4.py` 使用 Blender 5.2.1 的原生网格、UV、BVH 与 Cycles，参数 `--render` 输出同角度灰材和基础色图，CPU 固定 2 线程、8 samples、1024×800。脚本使用 `--python-exit-code 17` 运行；未通过几何断言时不渲染，不降低门槛。

`root_buttress_h10_form_p4.blend` 保留分件编辑。新几何使用从 p3 原生源中读取的石/木材质配方，避免把旧模型的打包 atlas 直接错贴到新 UV 上；SapKnot 的原材质与 UV 保留。图中临时使用灰色/基础色覆盖材质，检查形体，不拿纹理细节掩盖结构。

`p4_geometry_report.json` 包含当前实际顶面、足点、靶 LOS、根连接、包围盒、UV、三角数和冻结文件校验。它是 Blender 内的离散几何检查，不能代替 Godot 中冠兽与飞行体的真实扫掠。

`review_v1/` 保留首轮脚本、日志、两图与报告：当时 17 项几何通过，但自行退回宽根带、孤立后尖岩和桌沿感。数字通过没有被写成造型通过。

`review_v2/` 保留第二轮：主根已使用真正三股不等径几何，但后残脊仍像整片斜板，中层台面在固定方向下露出不足。当前第三轮扩大了旧边界内的左台前沿、降低后残脊；没有继续增加装饰或纹理。

当前源有 42 个可编辑网格、14,950 个三角形，17/17 几何门槛通过。实际包围盒 Godot 为 min(-6.38542,0,-6.56063)、max(6.70090,11.80308,6.71360)。最终两张 PNG 已逐张实际查看：左台外缘与三股根比前两轮可读，但主安全面仍宽且规整，前主根仍有并排束带感，侧面大断面与参考的天然岩壁细节还有距离，后脊仍需要主线程审美复核。不能据此进入“最终美术已过”的结论。

## 尚未消除的限制

中央大面积平顶仍受战斗承重硬约束限制；边缘可改变，安全区不可用凹坑或装饰伪装。当前没有靠随机碎石增加密度，也没有加入苔藓贴片。模型的材质投影、最终 PBR 烘焙与游戏相机读形都还没有在新形体上验收。岩石纹理层理不作为真实几何分层的证据。

两张图保持同一固定游戏相机方向，但使用单件取景（正交尺寸 26.5、目标 Godot(0,5.3,0)）；不是实际游戏截图的完整相机变换，也不是与旧实机图严格同状态的图像对照。
