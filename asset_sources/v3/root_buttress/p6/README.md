# H10 自然形体来源试验 P6 — 形体退回

2026-10-18。本目录只保存自然石体来源与方法试验，没有材质烘焙、GLB 导出、Godot 导入或运行资产替换。P2 运行四高度、P3 材质候选、P4/P5 源均保持原字节。

## 真实结果

`h10_p6_natural_stone_default.png` 是当前可编辑源的唯一默认角度基础色离线快图，Cycles CPU 2 线程、8 samples、1024×800。没有使用扫描照片纹理，SapKnot 仅在本次石体图中隐藏；它的几何、UV、变换仍保留在源内。

逐张对照已批准的 `references/v3/production/root_buttress/root_buttress_reference_v1.png` 后，**本次美术形体退回，不进入材质或整体资产阶段**：

- 按每个竖向柱的最高表面映射到目标高度，使原扫描岩形变成下垂帘状长沟，缺少参考中的短宽岩层与清楚断面。
- 四处真实足面虽满足 Y10 支撑，仍显出圆垫形痕迹，未融入自然侵蚀面。
- 后侧残脊像插入的孤立薄片，左侧中台在此角度也没有参考那样清楚。

这不是纹理不足。不能通过增加裂纹、苔藓或岩石贴图掩盖当前形体。后续建议由主代理决定：保留原石体比例和天然结构，采用旋转、相互咬合和少量局部切削形成足面；停止逐竖列拉高顶面。此建议尚未实施。

## 来源与实际方法

官方 [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01)，作者 **Kless Gyzen**；Poly Haven [CC0 许可](https://polyhaven.com/license)。准确下载链接、官方 MD5 核对、SHA256、字节数位于 `vendor/provenance.json`。仅取得六件石组 glTF 与几何 bin、两份小型 API 元数据，未取得或使用摄影 PBR 图。原始文件只读保留。

旧 Coast Rocks 是 59.5×3.3×42.5 m 的浅海岸地表单网格，未用作高台。已有 Island Tree 的下部树干可供独立根形研究，本次石体未引入该树或任何根网格。

本次使用 Rock04 为主体、Rock02 为右前支撑肩、Rock01 为左中台、Rock03 为后脊。先各自缩放/旋转，再依据实际足点连续变形；一次局部布尔减法开放左中台；0.12 m 体素并集和两次轻平滑形成单一雕塑基底。独立源块存于隐藏集合 `P6_EditableNaturalPieces`，可编辑而非覆盖原始下载件。该流程实际产生了上述视觉缺陷，不能当作已验证的后续生产流程。

## 数值边界与证据

`p6_geometry_report.json` 的 **12/12 项数值检查通过**，只证明本次检查项目，不代表形体通过：

- 四个真实爪位 XZ 为 (-2.54, 2.17)、(2.51, 2.22)、(-2.28, -2.50)、(2.31, -2.48)，每处中心及半径 0.25/0.5/0.75 m 共 193 个垂直射线探针均命中 Y10。
- 左中台五点命中 Y5；三条前侧探针先命中 SapKnot，没有被岩体遮挡。
- SapKnot 的几何/UV/变换与四锚点未改；原边界、P2/P3/P4/P5 冻结检查通过。
- 石体 96,492 三角、48,248 顶点。本阶段没有运行预算验收、全兽碰撞扫掠或真实游戏相机检查。

Godot 坐标石体包围盒为 (-6.211935, 0.007556, -5.915734) 至 (5.091161, 11.191492, 6.215683)。四锚点仍为 GroundOrigin=(0,0,0)、BodyPerch=(0,13,0)、HostTarget=(0,11,4.5)、LowerShelf=(-3.7,5,3.2)。UV 是临时平面编辑 UV，不能作为最终 PBR 展开交付。

## 首次数值失败保留

`technical_reject_v1/` 保存首轮源、日志、脚本和报告。首轮右前足实际缺少岩体支撑；逐列变形在边缘射线误差处超出上界；Sap 射线未应用对象世界变换。第二轮增加不同来源的真实石肩，限定变形归一值并修正世界坐标 BVH，保持原检查门槛后通过。首轮没有出渲染图，第二轮完成渲染并退出后即释放 CPU 窗口，没有继续盲目渲染。

`manifest.json` 记录本目录证据的字节哈希；`selfcheck.json` 是文件存在、SHA 和运行 P2 冻结的轻量核对，不是美术或游戏验收。
