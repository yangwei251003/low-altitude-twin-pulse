## 可编辑的实际分区

参数集中在[finish_layout.json](finish_layout.json)，坐标单位为资产自身Godot米制。下表为作者指定的材质解释，不是扫描得到的物理PBR；尺寸是遮罩支持范围，不是已渲染可见面积。

| 使用原因 | 源位置与尺度 | 对PBR的实际作用 |
|---|---|---|
| 不连续盐垢 | 两护板低边共7个不等长斑块，另3个位于相邻低边梁；横向半径0.33–0.62m，竖向半径0.10–0.19m。南北位置不同，较高漆面不铺盐 | 局部偏灰矿物底色、粗糙度增加、浅浮凸；盐层处Metallic回0 |
| 少量螺栓流锈 | 只选6个真实X[-2.965,-2,-1,0,1,2,2.965]及Y.09/.91的紧固点；从这些点向下0.13–0.29m，横向半径17–25mm | 棕灰氧化色、粗糙度增加、非金属；不在每根竖肋复制整条锈线 |
| 折边露底 | 8段有限折边，横向半径0.15–0.28m、竖向15–20mm，细噪声仅破碎局部边界 | 失漆处显露钢底色与Metallic，其余完整蓝绿漆保持介电 |
| 手柄抓握 | 锁环3处局部弧、手动U柄上横段2处；半径23–67mm。其他黄漆保留 | 同一有限遮罩控制钢底色、金属与磨光粗糙度；不把整柄改成裸钢 |
| 甲板通行 | 沿真实X向过桥，中心Z小幅弯移，主要宽约0.66m、软边最宽1.72m；另6个有限长擦痕，长约0.58–0.94m | 宽带仅轻微色差、粗糙度增加；局部擦痕沿X走向。真实2.8mm防滑凸纹和6片浅板缝不改 |
| 轴承油污 | X±2.83两小车、Z±.38共4轮的两侧轴承，8个实际坐标；径向90mm、轴向半厚55mm | 局部深油色与更低粗糙度；钢轮外圈仍保留干净金属，不把整车涂黑 |

蓝绿完漆基色`12343d..1b424a`、灰甲板`323a40..465055`，保持色相职责。完整漆Metallic=0；没有发光。最大源Bump距离0.6mm，用于盐层/失漆的浅响应，不能充当结构凹凸。所有高频噪声只提供低强度微表面或已限定斑块边界，不能自行产生全表面可见污点。

## 从泵房借用的可交付方法

只读检查了`clinic_pump_shell/prototype_v8/frozen_v4_material_support.py`及`delivery_v8/common.py / bake_source.py / export_asset.py`：其可信之处是明确UV采样、原图字节保留、按角点传递属性、独立DeliveryBakeUV及烘焙后按原分组恢复。没有把泵房建筑图案、图集或最终运行材质搬到桥上。

本源新增`SourceXZ=(X,Z)`与`SourceY=(Y,0)`显式UV，值由同一份模型顶点米制坐标写入；`WeatherUse`是CORNER浮点属性，分别标识漆/甲板上面/抓握/小车。材质只读这些命名数据，不读Generated、Object、Position、相机或灯光。对象分开、桥位移、锁销下落时，材质斑块不会滑移或按每个物件重新缩放。Bevel生成的面会继承这些数据；构建中读回全部 evaluated loops，检查映射偏差不超过6mm（原结构倒角最大3mm）。

`SurfaceUV`仍是显式活动源投影，**不是最终独占图集**。下一阶段如获许可：按原三角角点复制这些命名UV/属性与法线到烘焙proxy，另建独占`DeliveryBakeUV`，分别烘焙无光照BaseColor(sRGB)、ORM(Non-Color：R=1/G粗糙/B金属)、该BakeUV上的切线Normal；分回12件时把相同BakeUV改名为唯一`SurfaceUV`。最终材质仅采对应贴图并检查实际GLB像素/UV/法线。现在只保证源码有可审查的PBR输入路径，未宣称烘焙/导出成功。
