# P1 单件建模与烘焙脚本准备

当前状态：**SOURCE_RENDERED_VISUAL_REJECTED**。已实际运行并保存可编辑源、四张2k原生PBR烘焙及完整1280预览；实际3276三角/77件，9项几何UV检查过，重开四图路径/哈希/实际像素读取通过。美术自审退回过亮、骨料水磨石感、侧面投射竖纹，见 `evidence/VISUAL_REVIEW.md`。没有GLB/Godot或最终美术通过。以下准备段保留流程说明，以本段和实际报告为当前状态。

`build_ground.py` 计划建立 77 个独立可编辑构件：四大板、三块排水边/端混凝土、三条真实低置封缝、槽底、16 边框、24 栅条、8 下撑、16 栓头与2端壁。四大板以两个错开 T 缝相接；格栅、端框、螺栓最高 Y0，槽底 Y-0.075；全件 6×6×0.18m。沿参考取材料和使用痕迹，格栅宽度仍按真实合同 0.28m，未放大迁就概念透视。

运行前输入尚缺：根生成并实际查看的四区平面 atlas 路径与 SHA，写入 `input_config.json`。该文件当前为空会直接阻止启动；不以现成 gravity 接缝图或整张带光照概念图代替。生成提示词为上级 `material_atlas_prompt_v1.txt`。

源图像只原字节复制。Blender 编辑节点以世界米制位置采样没有接缝的材质区；修补边界、槽边湿尘和黄角标另由明确坐标遮罩定义。局部锈位置对应真实栓头。真实接缝/孔槽来自网格。源材质保存 fake-user 可编辑节点图，之后通过原生 EMIT（base/rough/metal）和切线 NORMAL 烘焙成四张 2k PNG；法线仅浅颗粒，不从原图阴影猜深几何。图像精度受生成区域真实像素限制，2k 烘焙不能创造原图不存在的细节。

计划所有独立源件共享一套不透明 `CGround_BakedPBR`，按 `ConcreteSurface` / `DrainAssembly` 分组，未来显式 GLB 临时合并成 2 meshes / 2 surfaces / 1 material。当前静态估计约 3.2–4.8k 三角，实际 evaluated 回读超过 5k 会报告并停止，不称预算达标。源件不附 collider。

已准备的执行命令，**仅获根明确 CPU2 窗口且 atlas 配置完成后执行**：

`python ./asset_sources/v3/clinic_ground/p1/run_preview.py`

CPU2，300秒限时，只终止自身 PID 的进程树。预计约90–180秒，真实时间待执行。先实际 evaluated 尺寸/闭边/槽内射线/顶面/UV检查，再烘焙；失败保存 `FAILED_geometry.blend` 和报告，不靠图片掩盖。通过才保存可编辑 `.blend`，重新打开它，以 `bpy.path.abspath` 解析四张图的实际路径/哈希，再输出完整中性基础镜头一张。当前脚本不导出 GLB、不写运行 assets、不改当前地面/物理。

限制：单件逐块闭合不等于穷举自交；螺栓/框、格栅/支撑为真实交埋装配。输出图还须亲看色阶、粗骨料尺度、排水阴影和重复性；退出0或数值通过不能替代参考还原/真实Godot镜头。
