# Plain V2：真实半接缝，不用污渍遮拼口

**PREPARED_NOT_RUN**。唯一写plain_v2目录；P1/P2/delivery/plain_v1和运行场景全部只读，尚未启动Blender/Godot。根退回V1原因是模块间外接缝细浅，与内部20mm缝不一致；本版只修这一项及其必要承托结构，不增加噪声或新图。

## 几何合同

- 整件仍X/Z±3、底Y−0.18、最高作业面Y0；不挪模块中心、不改变6m网格或抬高避免闪烁。
- 普通四边混凝土**顶面**各内退10mm，独立封胶带填这半条缝，顶Y−0.012、底Y−0.035，与内部封缝同高同材质。两件相邻组成20mm密封缝。
- 半缝下有实际混凝土边床Y−0.18..−0.035；封胶底与其顶面精确接触，不悬空，不把整块板外缘挖到底。西/东边床与封胶贯通Z，南/北条只填两者之间，角处不重复叠面。
- 内部长缝、左右T封胶在外封胶边止住，避免交叉处叠出更黑贴片。四大板保留错列T和4mm内向倒角；外侧额外不规则小缺角取消，避免半缝被角落放大，原内部切角保留。
- 每件4板+3内部封缝+4边床+4半缝，共15个可编辑闭体。接触件独立保留，实际每块闭合检查；不把正常隐藏接触面统称模型错误，不做整体体素。最终三角数必须实际记录，不能用原V1的632/676冒充。

封胶本体20mm；加上两侧原4mm倒角，近看坡面+黑缝可宽约28mm，内部缝也相同。不能将含倒角视觉宽度误报为20mm。运行仍保留原Y0保守碰撞，本源不生成碰撞体/可掉入小槽。

## 与冻结P2排水板接合

P2没有外半缝，普通V2直接贴上只得到10mm，不能谎称自然变20mm。采用明确参数 `p2_contact_edges`：与P2相接的**新普通板**一侧退20mm，其余边仍10mm；此侧全宽封胶由新件承担，P2所有字节/中心/包络保持不变。这样仍6m模块边界，邻接时不移开tile留空，不叠跨边贴片。

首个专用候选 `P2_W` 为新plain西边接P2东边；参数支持明确指定其它边，但本轮只制作此一个接口实例，不批量生成所有组合。它不用于普通A/B连接，否则变成30mm；根后续摆放必须按接口语义选择。参考展示中P2中心X−3、新P2_W中心X+3，真实共享边X0，P2排水槽在原位。

## 材质、UV和源

继续直接共用P2同四张原生贴图，正常A/B只有原整体UV偏移(0,0)/(0.67,0.43)m；不新生成图、不烘焙。P2_W沿用A偏移。使用冻结plain_v1已验证的米制UV采样与折返点拆面函数，新增边床采样干净混凝土、封胶采样原暗封缝区。可编辑集合A/B/P2_W保持各自中心原点；非A默认隐藏仅是源展示状态，不应被未来显式导出误判为废弃。
