# 固定落台 P4：顶面材质分区候选

状态：已完成一次 CPU 2 原生遮罩烘焙与单图源预览，等待主线程审图裁定；没有正式美术通过。原 P3 源、PNG、烘焙法线与日志均保留，哈希列于 `p3_frozen_inputs.json`。

P3 的失败是甲板大尺度仍像均匀灰面。其法线 tile 实测只有 6,720 / 262,144 像素偏离平面法线；平顶凸纹本身不会增加法线差。因此 P4 保留原 95 mm 节距、60 × 8 mm 双纹、1.8 mm 凸高、高模顶点/面和法线强度，改为解释真实凸纹各表面的材料响应。不能把本候选称为材质通过。

## 明确改动

| 层 | 位置依据 | 材料响应 |
| --- | --- | --- |
| 凸纹顶面 | 同一可编辑高模的顶面，通过同一 TreadUV 原生 EMIT 烘焙红通道 | 温灰钢 `737b78` 混合 0.62，踩踏处最多 0.82；粗糙度降低 0.30，不发白、不发光 |
| 斜侧坡 | 同高模侧面，绿通道 | 克制露钢，颜色混合 0.20，粗糙度降低 0.12 |
| 低凹底 | 同高模低平面，蓝通道 | 低频细尘权重 0.10–0.23，踩踏带中减少最多 80%；无额外深遮挡 |
| 两条不规则行走带 | 地板沿通路的真实米制坐标，横向约 -0.48 / +0.38 m | 半宽 0.24 / 0.29 m，另有 0.24 m 柔边与最多 0.12 m 弯曲；低频断续磨亮、粗糙度降低，不重置成每块板重复条纹 |
| 板缝积尘 | 每块真实 walking plate 的边界 | 8–45 mm 范围递减，颜色仅局部暗化 |
| 紧固点接触 | 每块板四角实际 45 mm 内缩的紧固件中心 | 半径 14–78 mm 的局部接触环，避开真实螺栓覆盖区 |

原始 P3 法线为 `source_inputs/LandingTread_Normal_P3.png`，SHA-256 `08f9dc4e90df6503d6d06efbb09c20c90db22341c5e737ca787cce8d329ee661`。不重烘、不增大 normal strength。

P4 只新增 512² RGB 语义遮罩原生烘焙，预计输出 `LandingTread_SurfaceMask.png`。它提供顶面/侧坡/凹底身份，不是从法线亮度猜分类。上述遮罩和米制磨耗均可进入日后的 BaseColor / Roughness / Metallic 原生烘焙；本轮不交付整件 PBR 或 GLB。

## 不变项与静态证据

- `geometry.py` 与 P3 原字节相同。21 个模型网格，修改器前 12,532 三角；66 项纯结构检查通过。修改器后的实际面数需由 Blender 新运行记录。
- 高模 tile 顶点和面逐项等于 P3。按原几何投影计算，顶面约占 tile 面积 2.757%，侧坡约占 2.561%。这是静态几何占比，不是尚未完成的 P4 烘焙像素统计。
- 所有 7 层 UV 显式命名。新增 `PlateMetres` 与 `PlateSize` 取自真实板片几何，纹样遮罩与法线共用 `TreadUV`。不得转为 Generated / 隐式活动 UV。
- 护板、承肩、固定面的包络/厚度、实际紧固件、开口和原碰撞范围不变。护板材质暂沿用 P3；本轮不靠改灯光、相机或曝光掩饰甲板问题。
- 同 01 机位、1400 × 1050、12 samples、CPU 2、AgX exposure 0.45；三盏光和环境光同 P3。只渲染一张 East 4 m 单件图，完整可编辑源仍含全部模块。

## 待授权运行

从项目根执行：

```text
python -u asset_sources/v3/shared_access_landings/p4/run_source.py --run-authorized-once
```

必须先由主线程分配串行引擎窗口。入口为隐藏进程，CPU 2，240 秒有界；超时只清理自身进程树。默认不带参数不会启动 Blender。没有 Godot / GPU / GLB 导出入口；Cycles 使用 CPU。失败应保留本批日志和输出，不覆盖或自动重跑。

运行后查看同机位甲板是否能读到连续压纹、局部磨亮与有依据的板缝积尘；同时检查是否出现白色贴花感或过于整齐的双带。上述视觉标准目前未验证。
