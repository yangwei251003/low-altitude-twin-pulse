## 表面来源与真实尺度

`source_inputs/maintenance_concrete_basecolor_v1.png` 是原生 imagegen 生成的一个材质单元，根已实际查看并批准用于 P2 对照。原PNG未改像素，1254²，SHA `a73b35e1aa42a0355ce46d7006ab9dbfdb7d9c7ece178900b25dd87668c4d744`。准确提示、原保存路径、输入图角色和边界诊断见旁边 `provenance.json`；原始生成图仍留在 `.codex/generated_images`。

主混凝土直接采用这个 sRGB 基色，`ConcreteUV=(世界X/4,世界Z/4)`，八块在共同世界原点上连续，绝不每片重置同一磨蚀斑。侧面按真实轴距同尺度投射。图片只提供颜色：不从暗色推挤出、不生成假AO/深沟，不再叠旧院面不匹配的normal；主面仅实际倒角参与几何光照，roughness .84 为作者近似。回填、标线和检修钢仍独立。

左右/上下边的8bit平均差17.04/16.72，内部邻列/邻行中位14.33/14.26，仅是静态诊断，不能据此宣称无缝完美。源对照必须查看4m重复后的边界和远距密度，后续正常mipmap须由真正导入验证。

| 层 | 本轮具体变化与依据 |
