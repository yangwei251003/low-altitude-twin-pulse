## 先解决八块铺装的用途逻辑

固定 5×4m、顶面 Y0、底 Y−.18。八个源变体来自同一构形器：中心 X17/22，Z−12/−8/−4/0。西列 W0..W3 各有一段实体检修带，世界 X[19.02,19.47]，沿 Z 连成同一工作带，模块接处保留真实密封缝；不是八条任意沟。东列 E0..E3 不设检修带，X[21.5,24.5] 保持 3m 通路。E3 唯一入口短标线，不画黄框；W1/E3 两处锯切回填，其余宽面安静。只有 W0/E3 的短接缝附近设低对比沉积色，不画连续白盐边。

盖框最高 −2mm、实体盖 −4mm，沉头紧固件最高 −6mm，凹把手最高 −17mm。盖板有真实孔和孔底，不能把低于整板的硬件埋在完整盖板里再称沉头。所有源件独立可编辑。只保守复用现 Y0 地面碰撞；这些表面凹处不假称新可通行空间。

## 接边与验证准备

- 内邻边各退 10mm：A+A 得到 20mm 胶缝。湾外边新件单独退 20mm，接未退缝旧地面：B+旧地面还是 20mm。统一胶顶 −12mm、底 −50mm，下方连续承床；外缘没有抬高路缘。
- 东西胶条贯通局部 Z，南北只填剩余 X，角部不叠双胶。内部 T 缝错位；锯切回填周围只有 8mm 窄胶口，不沿宽面画长裂。
- `check_plan.py` 只核对静态八块接缝归属、输入 SHA 和 Python AST，不是 Blender 几何证明。
- 运行后的 `production_report.json` 将用实际网格检查：每件闭合/正体积/零面积面、5×4×.18 包络、盖/把手上界、明确 UV 层、真实下射首面、10 条内部拼缝和 12 段外界胶宽。没有宣称全体交叠已穷举。
- 本轮两张离线图：W1 单件，以及八件整体用途/重复节奏。完整模型不再靠白盐勾边。运行和审图均待根窗口。

## 复用生产链

只读使用院面 `plain_v1/build_plain.py` 的已验证米制干净区域采样和折返点拆面，`p1/build_ground.py` 的编辑件/Shader Graph 及作者通道记录协议。原 P2 BaseColor/Normal 和原始工业四区图保持原字节；BaseColor sRGB、Normal Non-Color。新灰面只取约20%的原混凝土层次，法线强度 .06，减少默认视角颗粒噪声。青钢只用局部细节，不使用全图接缝投影或新生成纹理。

`SourceUV` 明确保留来源采样，`SurfaceUV` 留给后续原生四通道烘焙；不把它们混用。后续若获批生产，沿现院面 `prepare_uvs/bake_and_apply` 路径选择一个变体/批次烘焙，应用统一显式 GLB 回读流程；本次没有编写另一个导出器，也不把作者 shader 宣称可直接等价导入。

来源 SHA 在 `contract.json`，构建前后都回读冻结来源。源内遮罩绑定模块根坐标，不用每块零件 Generated 包围盒；展示副本重绑对应展示根，避免平移后修补/标线漂移。
