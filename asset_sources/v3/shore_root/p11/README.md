# T03-A P11 — 冻结 P10 与实际根桥的只读装配检查

状态：已完成一次静态离线装配及同镜头图；未导入游戏、未进行运动机体或碰撞验收。没有修改 P10、原根桥或任何运行资产。

## 本轮纠正的判断

P10 单件图右侧的大竖直面确实是 `local X=4.5` 的桥端插接面，法线为 `+X`。它不是应当全部外露的自然岸壁。原单件自审把这个面直接当作外露大墙，需要以本轮装配证据纠正；不能据此推倒整个主岩体。

实际三角总面积为 **28.8044 m²**，范围为 Y `[-0.16451,4.5]`、Z `[-3.60446,2.95715]`。根桥采用实际冻结 GLB，仅做坐标转换，没有改形、缩放或转向：

- 岸肩世界根：`(-24.5,0,-6)`。
- 根桥世界根：`(0,0,-6)`。
- 根桥在岸肩局部：`(24.5,0,0)`。
- 实际 GLB `EntryWest` 转换后：`(4.5,4.5,0)`，与 BridgeJoin 对齐。

## 覆盖与接触须分开理解

从实际大面三角内取 4 cm 网格样本，排除地下部分，共 **17,463** 点。根桥查询只用运行包装实际采用的 `WalkableRoot`、`StoneRemnants` 三角，不以 AABB 或苔叶代替实体。

| 从接面沿 +X 到首个实际桥三角的距离 | 样本覆盖 |
| --- | ---: |
| ≤ 2 cm | 70.10% |
| ≤ 25 cm | 96.39% |
| ≤ 1 m | 99.97% |
| ≤ 3 m | 100% |

这说明约 30% 样本不在 2 cm 近接触范围内，**不能声称接面已全贴合、没有缝隙**。这些是单向三角探针距离，不是引擎中的实际接触解算。

保留原 P10 正交相机全部变换、16.2 m 视宽及 1400×1050 分辨率后，原先可见的面样本中 **99.8969%** 被桥的真实结构遮住。剩余 18 点约 `0.0288 m²`，集中在 Y `[3.2155,3.5755]`、Z `[2.8955,2.9355]` 的边缘。该比例只适用于此相机，不代表所有探索角度；4 cm 有限采样也不是解析精确并集面积。

## 唯一装配图的实际观察

`p10-with-frozen-root-arch.png` 由实际冻结 GLB 回导后与 P10 装配渲染。桥仅在本轮内存副本换成基础色，以辨认结构；P10 相机及源几何均不动。完整桥跨出画面右侧，因为这是岸肩接缝的原单件镜头，并非全桥展示。

图中大竖直插接面基本被原桥端头遮挡，支持上述判断。仍可直接看见横枝截断口、后方细枝，以及桥后岸肩上部的平切带；这些和被遮住的 X=4.5 接面不是同一问题。下一步若获授权，应保留主岩体，局部处理真正外露的枝基断口/根端接合，再检查外露上缘，不以重做整块岩体替代局部判断。本轮没有实施这些修改。
