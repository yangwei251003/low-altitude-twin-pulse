## 失败记录与方法修正

`first_basic_rejected` / `second_basic_rejected` / `third_basic_fold_rejected` 保留逐轮原图与源脚本：最初高沿形成刀脊；后续推移旧封侧顶点产生折面。闭合边检查通过也不能证明无自交，所以这些图没有进入材质阶段。

`boolean_crossing_diagnosis.json` 与 `boolean_crossing_double_precision.json` 记录原 P10 和切后实体各 25 组真正的三角自交，后者用独立双精度线段/三角算法全部复核；不是把检查器容差当作新造型缺陷。原 P10 文件未修改。

`build-basic-p12-h.log` / `p12_source_report_exact_self_failure.json` 保留 Exact Self Intersection 修复仍留下非流形边的失败。该选项参考 [Blender 官方说明](https://developer.blender.org/docs/release_notes/2.91/modeling/)，本模型不能仅凭选项开启宣称修复。

保留原 `x≥3.5` 桥口条、其余同形重构再精确合回的方案也被否决。首个 3.5cm 分辨率试验在 `build-basic-p12-i.log` 中因最大采样偏差 4.6757cm 超过 4cm 而停止；2.5cm 试验 `build-basic-p12-j.log` 的最大采样偏差仍为 4.4652cm，后续布尔还留下大量开边。`p12_repair_stages.json` 证明旧接口条本身有自交，原设置 Preserve Volume=true 的重构也有自交，不能把这两者直接并合。

主代理据此明确撤销本代理自加的“原 X=4.5 面逐顶点/拓扑不变”实现锁。实际要求没有降低：保持桥口平面、5.5m 净宽、接台位置、根端遮盖；允许改坏三角，不能宣称旧拓扑不变。下一轮 `diagnose_plain_voxel.py` 仅诊断 2cm 的原形体积网格，显式禁用 Preserve Volume 和 Fix Poles，不做投影、布尔、渲染或导出。两项设置同时变化，不能据此单独归因某个选项。闭体、自交排除和双向全顶点采样误差 4cm 仍为硬门槛。该距离只是明确采样检查，不冒称解析 Hausdorff 上界。

后续仍必须实际通过闭合/无自交、三处接触、183 根端点埋入、15 接口探针、实际 X=4.5 接口面和工程包络，再看基础色装配图。已准备的材质与 GLB 脚本不表示它们已执行。

### 几何检查的实际结论

`verify-boundary-classification.log` / `-b.log` 证明原三对横穿报告来自有真实共享边的原 polygon；原源仍检出 412 对非共面严格相交，12 个已授权局部偏差点依然全部位于真实旧缺陷。独立共面包含样例同时揭露 BVH.overlap(self) 漏候选，因此没有把这轮说成全部通过。
