# P9：保留天然粗叉比例的单根方向试验

本轮只研究 T03-A 岸肩主根的来源和摆位，没有制作完整岸肩、贴图或运行 GLB。`rigid-root-main-form.png` 是单件基础色 Blender 离线图，不能作为游戏画面、接桥成功或美术通过的证据。

原件来自 [Poly Haven Island Tree 01](https://polyhaven.com/a/island_tree_01)，作者 Rico Cilliers、Rob Tuytel，[CC0](https://polyhaven.com/license)。这里只读取 mesh 0 / primitive 0 的树干与粗枝（34,787 三角）；没有加载叶片和细枝的其余两个 primitive。原始 glTF 和 BIN 在前后均按 SHA256 核实未变，完整树干另保留在 `.blend` 的隐藏来源集合中。

这是树基与树枝分叉的转用试验，并非裸露树根扫描。自然分叉角度和局部粗细变化可以复用，是否符合承重根的生长方向仍需结合岩体审查。

## 实际处理

先按原 glTF 坐标保留 Y 0.1–2.2m 的树基和粗叉，再裁去 X > 0.4m。后一个平面经过两条已测量细侧枝，截面分别约 0.047×0.048m、0.090×0.124m，不经过树基。详见 `pruning_sections.json`。只在裁切面封口，没有重拓扑、减面、扭曲或非均匀缩放。

整体仅作统一 3 倍缩放和一次刚性转向。倾向参数为下倾 25°、绕轴 100°，以源点 `(0.0122867, 0.1, -0.0792143)` 对应岸肩局部 `(3.6, 4.15, 0)`；准确旋转矩阵在 `rigid_root_main_form.json`。

在测试的离散姿态网格中，未裁这两条细侧枝的较短片段最少仍超出高度约 0.69m；裁后找到 3 个满足工程外包络的姿态。本轮采用其中一个。该搜索不代表已穷尽所有可能姿态，也不证明包络内的分叉已有支撑。

BridgeJoin 工程目标仍为 `(4.5,4.5,0)`。该点与高端基部裁切平面的法向距离约 0.964m，最近采样基部顶点距离约 1.063m。因此高端必须由真实岩肩承接，并将断面埋入岩体；不能把这个片段拉长来宣称已接桥。

## 单图复看结论

`rigid-root-main-form.png` 中，从右侧高端粗基到左前下方主叉的收束、凹脊和不均匀截面得以保留，明显优于 P7 把低树基拉长后的平直纹理方向。这一部分适合作为下一次岩肩对位的来源候选。

仍有三个不能跳过的差距：上方长横枝抢占主轮廓；背后的细高枝尚未处理；高端裸露断面没有岩体承接。当前单根还没有参考图中的整体厚扁斜跨关系，也没有证明分叉顺着岩面着力。下一步是否做有界修枝与岩体对位，由主代理看此图后决定，本轮停止追加渲染。
