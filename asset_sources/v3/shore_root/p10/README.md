# P10：真实修枝与岩肩接触候选——形体自审未通过

`root-shoulder-contact-p10.png` 是本轮唯一基础色 Blender 离线图。实际接触与闭合检查最后达到 17/17，但形体不通过：高岩肩的大面积平切闭合面呈墙体，两条干扰枝仍留有明显断桩。不得据此进入正式贴图、烘焙、GLB 或运行集成。

根模型与岩面均为可编辑源，未改 P9、第三方原件、冻结根桥、运行目录或共享文档。所有输出仅在本目录。

## 实际处理与可保留部分

根来自 P9 的 Island Tree 01 / mesh 0 / primitive 0，在已有源 Y0.1–2.2、X≤0.4 裁切上，再按源 X≥−0.6 真实截面封口。整体仍是 P9 的统一 3 倍刚性姿态，未扭曲、压扁、拉长或重构根网格。对象名为 `P10_NaturalMainRoot_TrueCrossSectionCuts`。

这次平面裁切确实去掉了两个远端，但切口离分叉基部仍过远。因此只能称为“截短”，不能称为已完整清除上方横长枝与后方细高枝。以后若继续，应定位各自的分叉基部作局部截面切除，避免继续用全局平面误伤主叉。

高端 183 个切口顶点已全部进入真实厚岩体。桥端最后一米以 15 条探针检查 5.5m 宽、Y4.5 的精确接口。根、高岩肩和三块低石体各为单一闭合组件，无开边或非流形边。检查详见 `p10_geometry_report.json`。

## 高岩体方法与失败原因

主岩面来自 Rock Face 01，先刚性转正、统一 1.10 倍、绕竖轴 35°摆位，保留自然外壁作为造型来源，再补 4.5m 厚的背体、边界封口和最后一米桥接口。原始外面副本和融合前厚体保存在 `.blend` 隐藏集合中。

源网格在焊接接缝后有两条三面共边。依据 `cliff_source_topology.json`，只在 P10 副本移除了 face 12891、13431 两个已定位微小翻片；原始下载文件未变。

精确并集在天然折叠边界与接口处产生破面，失败报告已保留。最终对石体副本作 0.065m 体积融合，再重新切工程界限；Rock04 自身扫描小洞以 0.035m 重构封闭。此后产生的一个 8 顶点孤片，实测范围约 `0.254×0.164×0.170m`，位于 `x[-0.223,0.031], y[3.508,3.673], z[-0.859,-0.689]`，远离根端/桥口/地面支撑点，仅按该确切范围移除。所有细节都在最终报告中；这不是“未改扫描拓扑”。相关原生工具说明见 [Blender Remesh API](https://docs.blender.org/api/4.5/bpy.types.RemeshModifier.html)。

实图表明技术闭合没有解决造型：为了补厚和接口而产生的高平面占据主要可见面，天然断崖的形体被挤到背面。5.5m 接口只要求接触带精确，不能据此把下方整面都做成平墙。以后若继续，应先把可见侧面本身替换为有实际深度的自然岩面，并让新增闭合面退到不可见的埋地/内部位置，不能靠贴图掩饰当前墙体。
