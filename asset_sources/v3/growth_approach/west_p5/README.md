## 最短失败诊断

1. **摆放依据不充分。** `append_scan` 按源 AABB 中心归中，再施加手定等比缩放/刚性姿态；没有先用合同高度的实际截面检验覆盖。AABB 高度和最大宽度不能证明那个高度具有同样截面。包络宽度最大仅达到 Z±1.4663，已不可能覆盖正式唇 Z±1.5 的全部边界。
2. **接口出现真实缺口。** 西端五点仅中点覆盖；桥唇 31 点中 25 点失败，鼻端 31 点中 23 点失败；中央承载带 205 点中 68 点失败。部分是射线无命中，部分命中高度低于合同；不是精度容差问题。鼻端例：Z≈−1.093 时实际 Y4.1684，要求 Y5.20。原始各点保留于 `geometry_report.json`，没有放宽 0.2 mm 检查。
3. **主要体积没有被裁掉，而是被旧台遮住。** A/B/C 切后原始网格体积分别保留 99.3% / 79.5% / 53.2%，合计约 76%。只说“合同裁面吃掉大部分自然体积”不符合数据。实际装配中旧台前侧遮住下部，新件露出的主要是平切顶面；南根仅露一团木色和尖端。单图人工估计外露候选约占画幅 4–6%，**不是精确遮挡率**：本轮没有单独候选投影/ID mask，不能据合成 PNG 报告“候选被遮住多少百分比”。
4. **还有独立正确性问题。** C 岩在互减后存在 3 条开边和 3 个面积低于原门槛的面；南根两个采样位置没有石面支持。源 Boulder 附带 `DataTransfer` 和 `Auto Smooth`，脚本保留它们并在之后施加 Boolean，日志明确提示修改器非首位；只读原生源 SDNA 已核实其存在。不可把本轮平滑发泡般表面当成原始岩块质量，亦不可声称原始 mesh 检查等价于完整求值渲染。

**制作边界需要 root 重新确定：当前局部引桥的大部分体积处在旧台的可见外壳之后，5.25 m 高孤件的完整侧岩/根轮廓并不会在这里出现。** 下一步应先确定真正会露出的桥口和台缘过渡表面，再决定如何使用天然岩体；本报告不授权或开始另一轮建模。
