# 西引桥重设计：先构造岩体，再接接口

2026-10-18；routeId `5e455d78-37b2-423b-b660-0cc3185eae49`。本目录只有研究与下一稿建议，没有新模型、渲染、安装或运行修改。P1/P2/P3全部冻结，P3数值通过不构成美术通过。

## 失败根因与改变的方法

本轮重新实际查看批准v2、三稿同向离线图，并读当前JSON和P3源。P1是盖板加柱；P2保留盖板并把叉根挂在其下；P3消除了薄片，却仍是带矩形凹槽的柜体。源代码 `make_top` 先复制整个矩形顶面，`upper` 将全圈边沿下拉成层，统一 `groove` 再挖侧槽；天然根最后刚性塞入。这一构造顺序决定了建筑轮廓，增加倒角或噪声无法解决。

**下一稿改为：3个非轴对齐厚岩主块 + 1个较小锁石，先审三维体块和连续根路径，再把数值接口局部接进岩体。** 不继承P3拓扑，不先造满包络实体，不挖矩形根槽，不保留四块等高分层。中央承载面是局部接口，不是必须可见的整张盖板。

## 锁住什么，放开什么

坐标为Godot本地；世界原点(-14.5,0,25)，单位变换。硬包络X[0,3.75]、Y[0,5.25]、Z[-1.5,1.5]。西X0五点Z/Y为(-1.5,2.925269127)、(-1,4.129740238)、(0,4.070995331)、(1,4.065418243)、(1.5,4.081121445)。正式桥唇X3.5全宽3m、Y5.25；鼻端X3.75宽2.98m、Y5.20。八锚点、中央Z±0.85承载带沿当前JSON的原三角平面保持，碰撞仍来自可见面。

**可重新设计**：承载带以外的侧沿可降低/退让；下部全部体块分配、倾角、接缝、倒角和根的路径均可重做；不锁旧顶点、网格数或四块划分。正式桥口和西接口不能缩窄；自由侧沿不能新长高栏杆。全部根石守包络，因此不侵入西侧终点X=-15的光段。底Y0为实际落地，不是允许留四根细柱。

## 下一稿可直接执行的体块草案

下列是**构图范围，不是要填满的盒子，也未物理验证**。先用倾斜闭合多面体摆形，每块独立，不从矩形顶边向下挤出。

- **A主承载岩**：局部中心约(1.45,2.75,0.15)，主长轴在侧视倾斜约18°；从Y0.25跨至顶部中央约Y4.65，形成中前最大完整斜面。让它同时承担顶面和侧壁，禁止用独立盖板盖上去。
- **B东承唇岩**：中心约(2.85,3.45,-0.10)，与A反向倾斜约12°，下部伸到Y1.7；局部顶端收口到桥唇/鼻。其自由侧角做宽钝断面，不能延成长尖唇。
- **C西根脚岩**：中心约(0.65,1.5,-0.25)，从地面到Y3左右，宽底斜肩，与A错位咬合；上部只在需要处连接西接口，不延伸成环绕全部四面的同高腰线。
- **D小锁石**：放在A/B底部的一侧，视觉体量约主岩的1/3，只填真实拼接需要；不做第四根同粗柱。两条主缝在不同高度终止，折向不同，避免十字网格和水平贯通缝。

**根先定路径，岩再局部让位。** 主要可见根在+Z自由侧：建议中心线从(2.75,4.65,1.15)→(2.35,4.35,1.20)→(1.8,3.9,1.20)→(1.55,3.2,1.20)→(1.9,2.5,1.15)→(2.2,1.6,1.10)，先检查实际镜头投影；次根沿另一边短些，不镜像。宽约0.38–0.55m、法向厚约0.26–0.40m，变截面并在中段分一支。根前表面与侧岩形成清楚的高低差，只有两端和一处跨缝接触埋入；端部埋深继续实测，不能让“末端已埋”掩盖整个主体消失。路径和尺寸是初始设计，须按实际岩面和包络调整。

旧天然叉保留为源/截面参照，不再整叉硬塞或逐顶点投射到不连续岩面；后者在P3已实际造成大量自交。建议先用可编辑曲线、自定义非圆截面和粗细变化得到正确连续体积，再择合适天然源段补形；天然源不适配不强迫整叉复用。根分叉连接处局部融合，保持独立可编辑备份，不对已精确接口整件重网格化。

## 新外部证据与工具判断

- Jonnathan Mercado的一手岩石流程明确将程序实例/合并与手工控制整体形态结合。这里采用“先手控大形”，不复制随机散石：[原作与流程说明](https://godstepson.artstation.com/projects/Qr8gXx)。
- Dean Scott制作根系时先指定墙顶起点、需要避让的物体、地面终点，再组织分支，防止重叠面混乱。本件借用起终点与分叉组织；两条根无需安装Houdini求大批最短路：[作者过程](https://www.artstation.com/dean_scott/blog/Pwlm/tree-of-mystery-breakdown-roots-ground)。
- Blender官方Trim支持按手势增减体积，并以切面形成新Face Set；适合低分辨率大断面。本件用斜向Line/Lasso Trim限制主岩，不用Box Trim造矩形槽。官方也提示Exact在高顶点数下成本高，因此主形阶段不先继承数万面扫描网格：[5.2文档](https://docs.blender.org/manual/en/latest/sculpt_paint/sculpting/tools/trim_tools.html)。
- Blender曲线支持自定义完整截面、逐点半径/扭转和Taper；可保留粗根厚度及连续走向。Profile选项自身具有镜像重复，非对称根截面优先单独Bevel Object：[官方5.2文档](https://docs.blender.org/manual/pt/5.2/modeling/curves/properties/geometry.html)。

现有Blender足够；本轮没有值得新增安装的工具缺口。Houdini最短路的增益是大量根的避障生成，本件只有两条，安装和重建管线不解决当前体块判断。网页证据边界见references.json：部分官方页正文由搜索索引取得，ArtStation根文章直开仅回登录壳；未声称观看嵌入视频或运行这些作者的工程。

**下一实施门槛**：先灰材完整岩体+两条粗根，无苔无小石；在实际装配默认相机检查厚岩连续性、主要根是否可从起点追到终点、桥端是否还有纸片尖角。形态合格后再跑八锚点/承载带/全宽唇鼻/同面碰撞/两机体扫掠/光first-hit与逐网格自交检查。最后才进入UV/PBR。一次仅这一方案；若默认镜头仍像柜体或柱群，停止细化并交同镜头失败图，不继续靠偏移顶点和加纹理重试。
