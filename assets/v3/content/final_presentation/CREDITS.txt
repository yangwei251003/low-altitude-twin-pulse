clock, save mutation, network event, reward, automatic ending or input capture.

context rails have no target IDs. Dormant remnants are shown only from the
original committed-victory boolean supplied by the main game.

Development status: actual editable components authored; not run, rendered,
playtested or reviewed during this content-only production phase.
